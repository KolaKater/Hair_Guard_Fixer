# Hair_Guard_Fixer
I wrote an object protection module called Hair_Guard_Fixer in Python for Depth models with the purpose of correcting the mistakes of the depthmaps direcly from the depth models with a fast speed.
It is especially for Depth Anything and Anydepth SDT 

hair_guard_fixer.py has better result, it works betther with inpaint.
The smooth version is better for 3D conversion without inpaint, but sometime you don't see the improvement
